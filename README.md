# Daymark Mood Tracker

A small, private daily mood tracker built with plain HTML, CSS, and JavaScript. Your mood check-ins are stored in your browser using `localStorage`; there is no account or backend.

## Run it

Open `index.html` in a browser. No installation or build step is needed.

## Use it

Choose one of the five moods, optionally add a note, and save your check-in. You can update today's check-in without creating a duplicate, review earlier entries, and delete any entry from the history. The summary shows your most frequently selected mood. Your data stays in the browser on this device.
